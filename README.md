# MYZOO 撿貨核對頁

MYZOO（達新投資股份有限公司 / MYZOO日居倉）出貨作業用的手機掃碼核對頁。

🔗 https://yangho0614.github.io/myzoo-pick/

## 這是什麼

單一 HTML、零外部函式庫。每天把 ERP 匯出的 `YYYYMMDD達新出貨明細.xlsx` 丟進去，
就能用藍牙掃描器一箱一箱核對，掃錯會出聲音 + 全屏紅色。

## 🔒 資料不會外傳

xlsx **完全在手機本機解析**（用瀏覽器原生 `DecompressionStream` 解壓縮），
客戶姓名、地址、電話一個字都不會上傳。這個網站只是一個空工具，裡面沒有任何資料。

## 使用方式

1. 手機瀏覽器開上面的網址（**建議「加入主畫面」**，之後點圖示就開）
2. 選角色：撿貨 ／ 對單貼標
3. 選當天的 `YYYYMMDD達新出貨明細.xlsx`
4. 點一張單 → 一箱一箱掃

⚠️ 藍牙掃描器配對前，**iPhone 要先手動切成英文輸入法**。
連上藍牙後螢幕鍵盤會消失，那時就切不了了。

## 原始碼從哪來

唯一來源是主專案裡的 `撿貨核對頁.html`（artifact 片段格式，沒有 doctype）。
`index.html` 是用 `發布到web.py` 包上外層骨架產生的。

⚠️ **不要直接改這個 repo 裡的 `index.html`**，下次重新產生就會被蓋掉。
