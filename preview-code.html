MZ 小標籤 · 字級與間距

你要的：字稍微放大，但要跟上方條碼拉開，不要干擾。
下面四組只有這兩個數字不一樣，其他完全相同。每組上面是進行中的卡片， 下面是最矮的一列（單人、品名一行）—— 我實測過了，四組的卡片高度完全一樣 （跨單卡 164px、最矮卡 111px），因為左欄本來就比右邊短，間距拉到 17px 都還塞得下。不會變高，可以放心挑。

現在是 11px ／ 間距 5px。 5px 太近，等於黏在 21px 的大數字下面，眼睛會把它一起讀進去。

排法我推薦 B

  • 現在整張卡已經有黃色描邊在講「這項還沒撿完」，MZ 膠囊再來一個框，兩個框在搶同一件事的注意力。拿掉底色，強弱就分出來了。
  • 「小-大-小」把尾 6 碼夾在中間，不用加大字級就更醒目 —— 靠對比不靠尺寸，行高也不會變。
  • 只動 CSS，欄寬不變，其他畫面完全不受影響。

如果你覺得品名折行才是主要痛點 → 選 排法 E（左欄縮到 86px）。
如果現場是用嘴巴喊 MZ 編號在溝通 → 選 排法 D。
B＋E 也可以合併：MZ 去膠囊、同時移到品名下。要的話跟我說。
