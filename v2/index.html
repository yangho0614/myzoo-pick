貼上新竹物流託運總表（選填）

用「預覽程式」打開 達新出貨總數.pdf → 全選 → 複製 → 貼在這裡。只有收貨人對得上而且件數跟箱數一致才會綁定。平常不用做 —— 掃到不認得的物流標籤時，工具會當場問你這疊是誰的。

角色與進度

三種角色的進度各自獨立記錄。對單貼標是第二道覆核，看不到撿貨那段的結果 —— 這是刻意的。一人作業是撿貨與貼標一起做，所以它的顏色就是那兩個角色的顏色。

一天的流程

  1. 電腦執行 送檔到手機.py，當天出貨明細會推到手機
  2. 手機「檔案」App →「下載項目」→ 在上面選它
  3. 選角色 → 點底部待命條 → 點一張單逐箱掃
  4. 掃物流標籤上的條碼，可隨時切到那張單複查箱數

欄名靠 品項編碼 品項名稱 數量 銷貨單單號 客戶/供應商名稱 對位，順序不拘。檔案只在這支手機上解析，客戶姓名不會傳出去。
